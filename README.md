# GlassIntro

Плавные края окон, стеклянные значки ярлыков и мини-плеер для Windows 10 (1809 и новее) и Windows 11.

Скачай сборку: вкладка Actions → Build GlassIntro → раздел Artifacts. Распакуй папку целиком и запусти `GlassIntro.exe`.

Нажми на значок в трее, чтобы открыть панель. `Ctrl+Alt+G` включает и выключает плавные края. «Выйти и вернуть как было» отменяет все изменения.

Значки ярлыков меняются только в свойствах самих ярлыков, оригиналы сохраняются. Программа не меняет системные файлы и не внедряется в другие процессы. Ошибки записываются в `%APPDATA%\GlassIntro\error.log`.
