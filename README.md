# GlassIntro

Стеклянный стиль для Windows 10 (1809 и новее) и Windows 11: панель управления, мини-плеер, плавные анимации.

Скачай сборку: вкладка Actions → Build GlassIntro → раздел Artifacts. Распакуй папку целиком и запусти `GlassIntro.exe`.

Нажми на значок в трее, чтобы открыть панель. `Ctrl+Alt+G` включает и выключает стекло. «Выйти и вернуть как было» отменяет все изменения.

Программа не меняет системные файлы и не внедряется в другие процессы. Ошибки записываются в `%APPDATA%\GlassIntro\error.log`.
