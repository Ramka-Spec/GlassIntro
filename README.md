# GlassIntro

Стеклянный стиль окон для Windows 10 и 11.

Скачай `GlassIntro.exe` со страницы последней сборки: вкладка Actions → Build GlassIntro → раздел Artifacts. Или запусти `build_and_run.bat`, чтобы собрать программу у себя.

Значок появится в трее рядом с часами. Меню открывается правой кнопкой, `Ctrl+Alt+G` включает и выключает эффект. Выход через меню возвращает всё как было.

Программа не меняет системные файлы и не внедряется в другие процессы. Игры из Steam, Epic и Riot она не трогает. Другие можно добавить в список исключений.
